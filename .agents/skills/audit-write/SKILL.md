# Audit write

Read `docs/workflow.md` from the kit root. When used in another project, use its explicit configuration and acceptance sources.

Inspect the authorized source and pin its revision. Use templates/audit.md. Give each finding a stable ID. Record impact, confidence, evidence limits, and competing explanations. Keep proposals distinct from decisions. Do not implement changes during diagnosis.

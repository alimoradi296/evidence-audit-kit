# Audit triage

Read `docs/workflow.md` from the kit root. When used in another project, use its explicit configuration and acceptance sources.

Read each finding and current evidence. Assess impact, urgency, confidence, change risk, and effort independently. Recommend investigate, fix, defer, accept risk, reject, or supersede with a reason. Mark unconfirmed owners and deadlines as proposed. Do not treat ease of implementation as severity. Preserve existing authorization; triage alone does not authorize a fix.

# Fix write

Read `docs/workflow.md` from the kit root. When used in another project, use its explicit configuration and acceptance sources.

Read the finding and affected implementation. Use templates/fix.md. Name concrete changes, exclusions, risk, rollback, normal behavior, edge cases, and observable acceptance. Link the complete parent acceptance source when one exists. Split work if its boundaries become unclear. Document existing authorization without adding redundant approval gates.
